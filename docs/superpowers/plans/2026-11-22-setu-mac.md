# Setu on macOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Setu runs on John's Mac as a signed `Setu.app` LaunchAgent with the same file and screen tools as on Windows, plus a zsh `shell` tool, so agents on Linux can do Mac work and testing through an SSH tunnel.

**Architecture:**
- **Shared code.** The Windows-only seams in `Setu.Core` become platform-neutral:
  - the `IDesktop` check;
  - the key vocabulary;
  - the file options;
  - the split of the shell tools;
  - the shared startup.
- **New Mac projects.** `src/Setu.Mac` implements the seams with P/Invoke into plain C macOS APIs and Apple's command-line tools. `src/Setu.MacApp` is the Mac exe.
- **Build and install.** The exe is built on Linux. zsh scripts on the Mac wrap it in `Setu.app`, sign it with a stable self-signed certificate, and run it as a LaunchAgent.

**Tech Stack:** .NET 10 (SDK 10.0.114), C#, ModelContextProtocol.AspNetCore 2.4.0, xUnit v3, zsh, and macOS tools: `codesign`, `security`, `openssl` (LibreSSL), `screencapture`, `sips`, `lsappinfo`, `open`, `launchctl`, `perl`.

**Spec:** `docs/superpowers/specs/2026-11-22-setu-mac-design.md`. Read it first. This plan argues from it and does not repeat its reasoning.

## Review Focus

These inputs and failures are the ones most likely to bite and that no task's main tests cover. Each one's test is added to the task named.

1. **A symlink or `/System/Volumes/Data/...` path into a protected folder**, or a different letter case (`~/documents`). Expected: the protected-folder error, never a prompt. Task 4: `Protected_SymlinkFirmlinkAndCase_AllRefused`.
2. **`type_text` with emoji or other surrogate pairs at a 20-unit chunk boundary.** Expected: the text is typed intact. Task 8: `Chunk_NeverSplitsSurrogatePair`.
3. **A `shell` command that backgrounds a child (`sleep 300 &`) and then times out.** Expected: the child is killed too. Task 5: `ProcessGroupContainment_KillsBackgroundedChild`.
4. **A `screenshot` with `max_width` larger than the image.** Expected: no upscale, and scale stays 2.0. Task 7: `CapturePlan_MaxWidthLargerThanImage_NoResample`.
5. **`update.sh` run while Setu is already stopped**, or twice in a row. Expected: it succeeds and the permissions are kept. Task 13, checklist step 5 (run twice), plus a manual `launchctl bootout` before one run.

### Task 1: Spike on the Mac (throwaway) and John's first visit

This is a hard gate. Every later task rests on its answers. If signing or keeping the permissions fails and the `rcodesign` fallback fails too, stop and report to John.

**Files:**
- Create (not committed, deleted after): `spike/macprobe/macprobe.csproj`, `spike/macprobe/Program.cs`, `spike/macprobe/run.sh`.
- Create (committed): `docs/superpowers/specs/2026-11-22-setu-mac-spike-results.md`.

**What the probe does.** It is a console exe (osx-arm64, single-file). On start it appends one line per probe to `~/Library/Application Support/setu-spike/probe.log`, then stays alive for 60 s so the alerts it raises stay up. Probes:

| Probe | What it does and records |
| --- | --- |
| `preflight` | `CGPreflightScreenCaptureAccess()`, `CGPreflightPostEventAccess()`, `AXIsProcessTrusted()`. |
| `request` | Calls `CGRequestScreenCaptureAccess()` and `AXIsProcessTrustedWithOptions` with prompt=true, once. |
| `names` | The number of layer-0 on-screen windows from other PIDs, and how many have a `kCGWindowName`. |
| `capture` | Runs `/usr/sbin/screencapture -x -t png <tmp>`; records the exit code, the stderr and the PNG size. |
| `type` | Only when `SPIKE_TYPE=1`. Posts CGEvent unicode key events for `spike123` then Return. |
| `securein` | `IsSecureEventInputEnabled()`. |
| `lan` | Only when `SPIKE_LAN=1`. A UDP connect and send to `172.16.1.4:9`, then a TCP connect to `172.16.1.4:22`; records success or the errno. |
| `folder` | Only when `SPIKE_FOLDER=<path>`. Times `Directory.EnumerateFileSystemEntries(<path>).Take(1)` with a 20 s watchdog; records "returned in N ms", "error X" or "still blocked at 20 s". |

`run.sh` does the work on the Mac:
- builds the `Setu.app` layout with `Info.plist`, including `NSLocalNetworkUsageDescription` and `NSAppleEventsUsageDescription`;
- creates the signing keychain and certificate exactly as the spec's *Packaging, signing and locations* says, including the search list, the non-empty PKCS#12 password and the partition list;
- signs by SHA-1;
- writes a LaunchAgent with label `com.greatworx.setu` and the final paths, so the grants carry over to the real install;
- bootstraps it.

Environment variables go into the plist's `EnvironmentVariables` for each run.
